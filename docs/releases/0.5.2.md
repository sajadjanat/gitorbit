# GitOrbit 0.5.2

Repositories now open on Version Control, including repositories with outgoing commits. The repository tabs are ordered Version Control, Push, and Git graph.

Side-by-side diffs scroll together horizontally and vertically. Both columns share the same horizontal travel, even when their content widths differ, and remain aligned when the window is resized or another file is selected.

Hold Shift while using the mouse wheel to scroll code horizontally in either diff column or a new-file preview. Pixel, line, and page wheel input are supported; regular scrolling and zoom shortcuts keep their existing behavior.

The application identity and updater signing key are unchanged. Existing GitOrbit and updater-enabled Workspace Monitor installations can update in place with saved workspaces preserved.
