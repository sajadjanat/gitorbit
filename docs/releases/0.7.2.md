# GitOrbit 0.7.2

Keep your work in place, compare branches file by file, and recover from Git errors with a clear next step.

- Commit drafts are saved separately for each repository and survive closing the details panel or restarting the app. Switching tabs retains selected files, previews and view state during the session.
- Open repository details refresh after successful monitor scans, including edits and commits that do not change summary counts. Background refresh preserves your draft and current review.
- Branch comparison now shows a changed-file list and the selected file's side-by-side diff. Both commit tips are fixed for the review; local edits are excluded. Renamed, added, deleted and supported binary files use their correct committed content. Multi-file patch boundaries no longer appear as changed code.
- Pull results link directly to recovery for sign-in, divergent history, local changes and unfinished Git operations. Sign-in offers an explicit retry, and batch retry targets only unfinished repositories while retaining successful results. GitOrbit never force-pushes or automatically stashes work to bypass a failure.
- Repository tools are available from every tab. Clicking the branch opens Branches directly, uncommon commit options stay in their menu, and comparison mode gives more room to files and diffs.
- Overview actions open the relevant review. Outgoing commit counts are localized, push routes remain readable in RTL layouts, and the return-to-commits action has a clear label. New recovery messages support English, Persian, Arabic and Simplified Chinese.

The existing application identity, signed update key and saved preferences are preserved, including updates from updater-enabled Workspace Monitor versions. The stable release is published only after signed Windows, universal macOS and Linux packages pass verification.
