# GitOrbit 0.5.0

GitOrbit now speaks English, Persian, and Arabic. Select a language from the header and the interface updates immediately, without closing workspaces or losing selected files and draft commit messages. Your choice is saved for the next launch.

Persian and Arabic include right-to-left tabs, tables, settings menus, repository panels, and Git history lanes, with Vazirmatn typography. English keeps its left-to-right layout. Paths, branch names, hashes, and source code remain readable in their original direction; before/after diff panes retain their familiar order.

All existing light/dark modes and color palettes work with every language. The same signed updater and application identity are retained, including updates from updater-enabled Workspace Monitor releases.

Available for Windows, macOS (Intel and Apple silicon), and Linux.
