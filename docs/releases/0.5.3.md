# GitOrbit 0.5.3

Review outgoing commit files before pushing: click a file in the Push tab to compare that commit with its first parent in a synchronized side-by-side diff. The file list replaces the outgoing commit list while reviewing; close the diff to restore the commits and your selection. Added, deleted, renamed, binary, root-commit, and merge-commit files are handled without changing local files or the staging area.

Recover from Git authentication errors: the Push tab now shows the remote host and a **Sign in to Git** button. Complete Git Credential Manager sign-in, then choose **Retry push** to send the reviewed commits. Sign-in uses a dry run, supports cancellation, and times out after three minutes. If the credential manager is unavailable, the app links to its official setup guide and lets you recheck. SSH remotes need an SSH key configured outside the app. GitOrbit does not collect passwords, and background scans do not open sign-in dialogs.

The new controls and guidance are available in English, Persian, Arabic, and Simplified Chinese.

The application identity and updater signing key are unchanged. Existing GitOrbit and updater-enabled Workspace Monitor installations can update in place with saved workspaces preserved.
