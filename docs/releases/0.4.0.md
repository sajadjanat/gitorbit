Workspace Monitor is now **GitOrbit**.

### What's new

- GitOrbit branding throughout the app, README and release packages.
- Crisp logotype lettering that adapts to light and dark themes.
- A larger transparent black-hole app icon, with updated Windows shortcuts and executable resources.
- Updated README screenshots showing the current interface.
- Linux DEB upgrades replace the former `workspace-monitor` package automatically and preserve saved workspaces.
- Signed Windows x64, macOS universal and Linux packages, published together after platform validation.

### Upgrade from Workspace Monitor

**Versions 0.3.0–0.3.2:** open **Updates**, then choose **Update & restart**. The existing update URL continues to work through GitHub's repository redirect. The same signing key and application identifier preserve compatibility. Saved workspaces, appearance preferences and update connection settings are retained. Verified legacy Windows installations are upgraded in place, with GitOrbit shortcuts and the new icon.

**Versions 0.1.0 and 0.2.0:** install GitOrbit once manually; those releases do not include the in-app updater. Future updates can be installed inside the app.

Windows installers and portable ZIPs are provided. The portable ZIP must be extracted before use; keep WebView2Loader.dll beside GitOrbit.exe. macOS uses the universal app/DMG and Linux provides AppImage/DEB. Update packages use the existing updater signature key; OS code signing and macOS notarization are not configured.
