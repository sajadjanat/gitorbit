# GitOrbit 0.5.1

Simplified Chinese joins English, Persian, and Arabic. All 256 interface messages are translated, the language choice is saved, and Chinese uses a left-to-right layout with system Chinese font fallbacks. Changing languages preserves selected files and draft commit messages.

The GitHub README now links separate Persian, Arabic, and Chinese editions. Each edition includes actual screenshots of the interface in that language, covering the workspace overview, Git graph, Version Control, and appearance settings.

The original application identity and updater signing key are unchanged. Existing GitOrbit and updater-enabled Workspace Monitor installations can update in place.
