# GitOrbit 0.7.1

Recognize file types at a glance and preview media without leaving your Git workspace.

- File lists now use distinct, locally bundled logos for languages, frameworks and file formats, including PHP, Blade, Markdown, JSON, React, images and PDF. Git status labels remain separate from file-type colors.
- Preview supported images with a transparency checkerboard, dimensions, file size, fit-to-view and shared zoom for before/after comparisons. Added or deleted images show the version that exists.
- Read PDF documents inside the app with page navigation and an offline renderer. Preview supported audio and video using playback controls without autoplay.
- Preview the actual working, staged or committed file content in Version Control, outgoing commits, history, saved stashes/shelves and revision browsing. Historical previews remain independent of local edits and handle renamed files.
- Unsupported binary formats show their file type, size and a clear explanation. Large files return metadata without loading their contents; media previews are limited to 16 MiB per side.
- Preview messages support English, Persian, Arabic and Simplified Chinese. File icons and preview backgrounds work with light/dark themes and RTL/LTR layouts.

Previews are read-only and do not stage, restore, commit or push files. Linked working files and folders, including Windows junctions, are not followed. Audio/video playback depends on the codecs available in your operating system's WebView. Password-protected PDFs cannot be previewed in this release.

Existing app identity, saved preferences and signed update configuration are preserved, including updates from the earlier Workspace Monitor name. The stable release is published only after signed Windows, universal macOS and Linux packages are ready.
