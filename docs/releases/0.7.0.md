# GitOrbit 0.7.0

Manage day-to-day Git work with a clearer Branches view, contextual actions and a separate Shelf for saved changes.

- Branches opens on your current branch. Local branches come first, remote branches expand when needed, and search reveals matching remote branches. Checkout, compare and merge stay easy to find; advanced actions and repository utilities use focused menus.
- Save selected work to named shelves, inspect staged/working/new-file diffs, and restore saved work with reviewed operations and recovery references.
- Use relevant context menus on repositories, changed files, outgoing files, commits, branches, tags and saved work. The workspace list separates changed-file totals from commits to push or pull, including individual files inside new folders.
- Permanently delete selected regular files from Changes or Unversioned files after reviewing their exact paths. Single-file and multiple-file actions use matching labels. Deletion does not use the Recycle Bin, stage, commit or push automatically.
- Stage individual text hunks or selected changed lines; review file history, rename-aware diffs, blame and historical repository files.
- Amend commits with reviewed author, sign-off and signing options. Reuse saved commit messages and templates.
- Manage remotes, initialize or clone repositories, inspect/update submodules, use selected-file stashes, manage tags and ignore rules, and export or apply patches through reviewed workflows.
- Review and reorder a supported linear commit sequence with interactive rebase, including pick, reword, squash, fixup and drop.

The interface supports English, Persian, Arabic and Simplified Chinese, with light/dark themes and RTL/LTR layouts. Narrow repository navigation and closeable branch comparisons are improved.

Git must be installed. Signing uses existing configured keys/tools. Interactive rebase, partial staging and other advanced tools have documented limits; this release does not claim full IDE feature parity.

Existing application identity, saved settings and signed updater configuration are preserved. Updates are published only after signed packages for Windows, macOS and Linux are ready.
