# GitOrbit 0.7.3

Arrange your workspaces and find daily Git actions in a simpler toolbar.

- Drag workspace tabs to change their order. The order is saved with your workspace settings and restored when you reopen the app. Workspace paths, auto-fetch preferences and the selected workspace are preserved when saving order.
- Use Alt+Shift+Left/Right to move the focused tab with the keyboard. Arrow direction follows the visual layout in both LTR and RTL. A destination marker shows pointer moves, and successful moves are announced to assistive technology.
- Cancel a drag with Escape or release outside the tabs to keep the original order. Failed saves retain the prior order and show the existing app error message. Reordering is disabled while settings are being saved or a repository operation blocks changes.
- Search, filtering, refresh, fetch and Pull all share a compact toolbar. Add repository stays next to the workspace name. Filtered result counts appear beside search only when a search or filter is active.
- Auto fetch is now in the Fetch settings menu. An Auto label indicates when it is enabled, without a separate settings row. Pull results remain available after an update.
- New labels support English, Persian, Arabic and Simplified Chinese. The layout adapts to light/dark themes and narrower desktop windows.

Internal tab dragging uses pointer events without adding a dependency or changing native file-drop settings. The existing app identity, signed update key and saved preferences are preserved, including updates from updater-enabled Workspace Monitor versions.
