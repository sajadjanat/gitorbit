# GitOrbit 0.6.0

Manage Git branches and recovery directly in GitOrbit. The new Branches panel supports creating, switching, renaming, deleting and publishing branches, configuring upstreams, tags, favorites and comparing revisions.

Merge, rebase, cherry-pick and revert commits with review confirmations. Resolve conflicts in a three-way editor, then continue, skip or abort supported operations. Stash changes, switch branches with smart checkout, undo commits, reset revisions and roll back selected files. Recovery references and stash backups preserve recoverable states before destructive operations.

Operations reject stale reviews and protect active Git operations. Remote branch deletion checks the reviewed remote tip. English, Persian, Arabic and Simplified Chinese are supported.

Interactive rebase, IDE Shelf and synchronized operations across multiple repositories are outside this release. Existing application identity and signed updater configuration are preserved.
